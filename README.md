# Boundary Club — Local Cricket Manager

Responsive local cricket app with a unique charcoal, lime, violet, mint and coral theme.

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser or use Live Server. No build tools are needed.

## Features
- Tournament creation with format, teams, overs, venue and date
- Add and score matches under a tournament
- Independent single-match mode
- Ball-by-ball score UI: 0, 1, 2, 3, 4, 6, wide, no-ball, bye, leg-bye and wicket
- Player profiles with editable runs, wickets, matches, balls and strike-rate stats
- Club overview, player leaderboard, local statistics
- Undo last ball, batter swap, bowler change and innings switch
- Browser localStorage persistence and responsive mobile design

## Limitations
- Data stays in the current browser/device. No cloud sync or shared multi-user scoring.
- Player lifetime stats are manually entered and are not automatically calculated from each match scorecard yet.
- Tournament standings are a basic local overview, not an official league points engine.
- Scoring is a friendly-match prototype; verify rules before using for formal competition.
